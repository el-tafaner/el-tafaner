## Qué vas a encontrar aquí

Proyectos didácticos pensados para aprender haciendo: código que funciona, tests y notas sobre el porqué de cada decisión, incluidos los errores por el camino.

## Cómo trabajo

- **Primero el test, luego el código.**
- **Decisiones documentadas:** cada elección importante tiene su nota, incluso las que se toman "para practicar".
- **Cuaderno de ingeniería:** cada hito explica qué falló y cómo se arregló.
- **Explicaciones en castellano, código en inglés.**
